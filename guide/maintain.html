How this kit is organized

START-HERE.html is the human front door. guide/ contains the offline HTML guide; docs-src/ contains its HTML sources. machine/ contains AI workflows. scripts/ contains measurement tools. examples/ contains original teaching passages and their generated reading pages.

The guide builder uses Python 3 and the copied Book Machine styling. It does not require the Book Machine folder, an internet connection or third-party Python packages.

Let the AI handle the setup.

You can read the included example right away. New measurements need a working Python interpreter.

The basic tool uses Python's built-in libraries. It does not need SpaCy, a reference-book collection, an API key, or additional Python packages. Your chosen AI app may have its own account requirements.

Copy this into your AI
Read stylo-starter/machine/SETUP.md. Check the folder access and Python runtime needed for the basic demonstration. Handle the steps your tools allow and explain only what I need to do. Don't download reference books, install extra packages, or change system settings automatically. If execution isn't available, help me open the included HTML example.

If Python is missing

You can still read the included comparison. If you want new measurements, ask your AI to help identify the next setup step. The official Python downloads page is the starting resource; you need not research a collection of tools.

If your chat cannot access folders

Attach machine/START.md, machine/SETUP.md and machine/workflows/first-look.md. Ask the assistant whether it can execute local Python files or only discuss them. If it can run uploaded code, supply the kit's scripts folder through the attachment method it supports. If it cannot, use the existing HTML demonstration.

Attaching text or reports shares their contents with that AI service. Measuring locally is a separate action. Start with the supplied fictional examples if you prefer.

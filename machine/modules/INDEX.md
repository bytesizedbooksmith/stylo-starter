# Optional modules
Default: none. Recommend at most one in response to a specific need.
- Personal profile and reference collection: machine/modules/profiles.md
- Different pen names or periods: machine/modules/pen-names.md
- Dialogue and narration: machine/modules/dialogue.md
- Advanced comparisons: machine/modules/advanced.md
- Book Machine connection: machine/modules/book-machine.md
- Longer manuscripts: machine/modules/longer-work.md
Record enablement in session-status.md. Switching a module off preserves files and author decisions.

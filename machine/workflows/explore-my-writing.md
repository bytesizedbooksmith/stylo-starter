# Explore a sample
Read machine/START.md and machine/SETUP.md. Invite a copy of an older or disposable passage. No backlist is required. One sample gives a description; two allow comparison. Do not sell a short sample as a complete voice fingerprint.

Ask only whether the author wants to notice patterns or compare two versions. Keep source files unchanged. Run the basic exploration script. Interpret at most three useful observations, referring to the actual report and passage.

Create or update voice-notes.md only with separate sections for measured observations, author-confirmed preferences, intentional exceptions and open questions. Refresh voice-notes.html from that Markdown using scripts/stylo/html_report.py's markdown_page function or equivalent safe HTML. Never invent preference ranges from one short sample.

Record paths, input fingerprints and next step in session-status.md. Deliver HTML. If the author is satisfied with what they noticed, stop.

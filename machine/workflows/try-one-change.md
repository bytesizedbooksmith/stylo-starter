# Try one change
Read machine/START.md. Use the current report, actual prose and confirmed author preferences. Offer one small experiment if requested, such as varying one paragraph's rhythm. Explain the possible reading effect as a possibility, not a guaranteed improvement.

When the author chooses, create a new candidate file; leave the original untouched. Preserve mixed emotions, deliberate fragments, punctuation and repetition. Do not rewrite the whole passage to chase statistics.

Measure original and candidate using scripts/stylo_explore.py into a new folder. Show the HTML comparison. Ask what the author prefers; “some of each,” “original,” and “neither” are valid.

Record the decision without automatically applying every suggested change. Never silently update a reference corpus with AI-edited candidates. Before replacing an existing file on explicit request, keep a uniquely named backup. End after the requested experiment.
